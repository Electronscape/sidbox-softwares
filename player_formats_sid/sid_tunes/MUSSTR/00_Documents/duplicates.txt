Additional Stereo
=================
When there are two versions, one mono and one stereo, with the mus file the same in both, then usually only the stereo version is kept.
However, when the stereo file is an addition by a different author than the original mono then both versions have been kept.

Kenneth_Barsky\Battlestar_Galactica.mus+str   Brian_M_Szepatowski\Battlestar_Galactica_A.mus       
Jerry_Roth_-Dr_J-\Long_Tall_Sally_B.mus+str   Jerry_Roth_-Dr_J-\Long_Tall_Sally_A.mus
