SIDNEWS#16.SEQ SIDNEWS #16 - SUMMARY OF AUX COMMANDS FOR MIDIPLAYER
By Craig Chamberlain 10/25/88


The following chart tells the meaning or effect of each AUX command value.  It should prove very useful while you are editing songs for MIDIPLAYER.

  AUX  DESCRIPTION
    0  set key color black
    1  set key color white
    2  set key color red (default for voice 1)

    5  set key color green
    6  set key color blue

    8  set key color orange
